这个 demo 用 Rust 处理路由和页面渲染。浏览器拿到的是完整 HTML：文章标题和正文不需要等待脚本下载后才出现。

## 从普通链接开始

列表里的每篇文章都有自己的地址。链接可以复制、在新标签页打开，也可以被键盘访问。刷新页面时，服务端仍能找到同一篇文章。

这是网页最朴素的契约，也是最值得先确认的契约。

## 内容和布局分开

文章正文写在 Markdown 文件里；标题、日期和分类写在文章的 YAML 元数据中。Leptos 页面组件负责结构，CSS 负责表现。改文章不需要触碰布局，改配色也不需要重写段落。

```rust
fn main() {
    println!("make the simple path work first");
}
```

示例代码只是文本，不会在访客的设备上执行。站点没有第三方字体、分析脚本或者前端包管理器。

## 验证真实的访问路径

编译通过不等于网页好用。要实际打开首页和文章，检查窄屏时导航是否可见、正文是否横向溢出，以及不存在的文章是否返回 404。

如果这些都做到了，一个很小的博客已经有了可靠的基础。之后增加真正的文章和栏目，可以继续沿着同一条路径扩展。
